# homebrew-tap

Homebrew formulae for [toolbox](https://github.com/WilliamThogersen/toolbox).

## Formulae and casks

### toolbox

Formula for [toolbox](https://github.com/WilliamThogersen/toolbox).

```bash
brew install WilliamThogersen/tap/toolbox
```

Source: `Formula/toolbox.rb`

### townhall

Cask for [townhall](https://github.com/WilliamThogersen/townhall). Townhall is currently in alpha.

```bash
brew install --cask WilliamThogersen/tap/townhall
```

Source: `Casks/townhall.rb`

## Maintenance

`Formula/toolbox.rb` and `Casks/townhall.rb` are written by each project's release workflow on every version tag. Don't edit them by hand.
